# Source attribution and rights boundary

This repository carries links, hashes and author-controlled validation material. A reference to public bytes is not a redistribution grant. Source-parent identities matter: views, months, paired weights and repeated runs are dependent observations.

| Source | Attribution and pinned evidence | Redistribution boundary |
|---|---|---|
| Original MWFAS Heuristic Metrics dataset | Soroush Vahidi, [Hugging Face revision `5b6cd562`](https://huggingface.co/datasets/SoroushVahidi/mwfas-heuristic-metrics/tree/5b6cd5620ca0a1c9b3be5e8d996bf8e3c467e79f) | Its own CC BY 4.0 grant is limited to creator-controlled content. Original historical graph/order inputs are absent. No data bytes are copied here. |
| Original MWFAS method code | Soroush Vahidi, [source revision `40209c26`](https://github.com/SoroushVahidi/minimum-weighted-fas-heuristics/tree/40209c26966247d9bf9ad34764de4ac4181f98c2) | This package links to the source and supplies an independent bounded adapter; it does not bundle that implementation. |
| Ali graph collection | Ali Dasdan and credited earlier graph creators, [collection revision `77e5b8b4`](https://github.com/alidasdan/graph-benchmarks/tree/77e5b8b4f1e1a1b8e80cfb9430f90492ffee3675) | Twenty selected source files have pinned hashes. The other rows document source-parent boundaries; they do not claim those files are in the release. No Springer template, proprietary solver file or third-party graph is bundled.

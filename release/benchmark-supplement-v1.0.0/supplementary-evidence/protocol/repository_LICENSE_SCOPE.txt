# File-scoped licensing and attribution gate

**Current status: candidate scopes, not applied grants.** The author has selected MIT for original code and CC BY 4.0 for author-controlled metadata, results, and documentation, while requiring file-level authority review. The repository remains private. `LICENSE` is deliberately not a blanket MIT or CC BY notice. Once the author confirms applicable agreements and each included file's rights, a later approved release can mark exact files as licensed and preserve their notices. [MIT terms](https://opensource.org/license/mit) preserve the copyright/license notice; they do not impose an academic-citation requirement. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) requires attribution and indication of changes within its actual scope.

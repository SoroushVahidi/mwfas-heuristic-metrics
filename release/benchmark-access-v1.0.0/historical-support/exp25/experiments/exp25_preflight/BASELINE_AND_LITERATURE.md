# EXP25 baseline fidelity and published-work matrix

This private review uses the published publisher versions linked below, the independently audited EXP09B/10/12/13/24 source checks, and the frozen repository history. The author-provided Xiong, Ben Ali and Qian PDFs were not mounted on this workstation. For Ben Ali and Qian, the publisher's accessible abstract/section preview supports the broad method description but **not** an exact replication of their full parameter tables, instance counts, seed schedule or hardware. No copyrighted PDF or third-party code is copied here.

## Seven requested works

| Final publication | Objective, graph representation, implementation actually established | Published evaluation and software/rights evidence | EXP25 compatibility |
|---|---|---|---|
| [Xiong et al., *Computers & Operations Research* 169:106724 (2024)](https://doi.org/10.1016/j.cor.2024.106724) | FASDC/SimFASDC reduction and divide-and-conquer for directed FAS; main evaluation emphasizes cardinality, with positive-weight formulation and limited weighted tests. The [authors' frozen source](https://github.com/forgottencsc/FindingSmallFeedbackArcSetOnLargeGraphs/tree/8340e1633ba9290a567a882aff4d74f01b38102d) maps `RASstar` to FASDC `r=1/3`, not standalone GreedyABS or all variants. | Published experiments span real graphs and circuits; exact original weighted cohort/clock details remain in article full text. Intentional restarts are a separate EXP11 controller configuration. |
| [Ben Ali, *Expert Systems with Applications* 238:122315 (2024)](https://doi.org/10.1016/j.eswa.2023.122315) | CL-TLBO maximizes a dense LOP precedence-benefit matrix via population search, recursive pivot construction and multilevel local search. | [Qian et al., *Computers & Operations Research* 115:104861 (2020)](https://doi.org/10.1016/j.cor.2019.104861) | Dense LOP block insertion: three local searches, block-insertion iterated local search and memetic algorithm, plus a parallel exact-subproblem framework. The paper credits Yanjun Qian for software, but no authenticated redistributable original source/revision was found in GitHub/web searches. | **Exclude now.** Neither the project's ordinary node insertion nor a conjectured block insertion is Qian's original algorithm. |
| [Cavallaro et al., *Journal of Combinatorial Optimization* 48:30 (2024)](https://doi.org/10.1007/s10878-024-01209-8) | MS-FAS, RBA/RFA, minimization and stabilization on simple directed graphs; published definitions and reported FAS sizes use **arc counts**, with SCC processing. | Open published article provides full algorithm sections, comparisons with Eades/Hecht, and synthetic strongly connected generator. Article is CC BY 4.0; no authenticated software revision/license for an executable was established. | **Exclude** as an original weighted comparator. Weighted rescoring of an unweighted method is possible only as a separately labeled heuristic baseline, not proof of weighted optimization fidelity. |
| [Cavallaro et al., *Computers & Operations Research* 184:107247 (2025)](https://doi.org/10.1016/j.cor.2025.107247) | Centrality/degree vertex arrangements followed by FAS minimization; published abstract describes FAS **size** reduction and average approximation ratio, not an established weighted-order optimizer. | Open-access publisher abstract points to benchmark URLs in paper, but an immutable original implementation and executable contract were not authenticated here. Exact dataset/parameter tables require full article review. | **Exclude** pending source/weight objective and order-contract authentication. The project WMSF/L2 label must not be equated with this external method. |
| [Hecht et al., *ACM Journal of Experimental Algorithmics* 26:1.5 (2021)](https://doi.org/10.1145/3447652) | ISO-CUT/TIGHT-CUT localize feedback sets in multidigraphs; the [published-version PDF](https://publications.mpi-cbg.de/Hecht_2021_7995.pdf) includes weighted cut theory, while its high-order runtime and set output differ from an immediately available complete ordering. | Article reports random and benchmark graphs. No frozen, licensed original executable with weighted whole-order adapter was authenticated in this audit. | **Exclude now** despite weighted theory: prove implemented weighted semantics, full-order conversion, practical cap and license first. |
| [Bader et al., *Social Network Analysis and Mining* 15:68 (2025)](https://doi.org/10.1007/s13278-025-01491-2) | Rocket continuous weighted forward-order stage plus Crane TopoShuffle/annealing, MIP and Monte Carlo stages, principally fly-connectome scale. CPU JAX Rocket is technically possible; GPU is an accelerator. | [Author repo](https://github.com/Bader-Research/MinimumFeedbackArcSet/tree/c30a6ac857c44e05833a8495781d97e2829deb44) has MIT notice and separately runnable components. [EXP09B fidelity audit](https://github.com/SoroushVahidi/mwfas-heuristic-metrics-data-paper/blob/40bc8ed8d4dd62c05dcd53c50a6893bdec578e61/experiments/exp09b_full_rocket_crane/FIDELITY.md) found no complete handoff driver or published warm-started MIP implementation; reported MIP stage is 20–40 min, beyond 120 s. EXP09 tested only a C component. | **Exclude full Rocket-Crane.** A CPU Rocket-only variant would need its own label and adaptation/graph-contract audit, and would not be the published full algorithm. |

Publisher access and search absence are evidence limits, not proof that Ben Ali/Qian software never existed. No author contact was made or authorized.

## Core implementation contracts

Read-only preflight verified that the private Wulver baseline checkout has Git HEAD `40209c26966247d9bf9ad34764de4ac4181f98c2`, resolves that object locally, and contains a Soroush Vahidi MIT notice. A GitHub lookup did **not** find that exact commit in the public `SoroushVahidi/mwfas-heuristic-metrics` or historical workspace repositories. Thus the source is immutable and available for internal audit, but an external reviewer does not yet have a verified public route to that exact implementation. The EXP12 wrapper/controller is separately pinned at research-repo commit `017b84bffa3ac9cad2f4553d93149605c4d158b2`; EXP13 reused it at `0559fac6f79654a7e7219c0ebb022cac3271d682`. Neither wrapper commit authenticates external authorship for LR-TA, WMSF or Eades.

| Arm | Source and provenance | Input, initialization, output, stochasticity and stopping |
|---|---|---|
| `lrta` | Project source `40209c26966247d9bf9ad34764de4ac4181f98c2`, local-ratio lineage; **not authenticated external author software**. | Strict positive-integer weighted DIMACS digraph with declared isolates; CPU/Python; deterministic `paper_fas_ranking_from_dimacs_fast(tol=1e-12)` returns complete CSV order, normally single-shot. A killed call has no order unless an atomic complete checkpoint exists. |
| `wmsf_l2` | Same project source, project WMSF/L2 implementation inspired by weighted/minimal FAS literature, **not Cavallaro executable**. | Same graph contract; deterministic `wmsf_ranking_from_dimacs_fast(ordering="L2", tol=1e-12)` returns full CSV order, single-shot. |
| `weighted_eades` | EXP12/13 project adapter, `igraph==1.0.0` lock, historical Eades lineage; **not original 1993 author code**. | Weighted `igraph.feedback_arc_set(method="eades")`, remove returned arcs, deterministic lexicographic topological order of retained DAG, independently rescore on unchanged original graph. CPU, full order only after adapter finishes. |
| `ipsns` | Project source above, `ipsns.py` SHA-256 `46a3f2b549897df1037ebe257e47b17490bddaa97effb2e31bce20a50ea54b36`; project method, 200 iterations. | Strict weighted digraph; WMSF/L2 full initialization is counted; `seed_ordering=L2`, `topK_scc=15`, `wmsf_seed_mode=full`, seeds 1/2. CPU/Python. EXP11 exposes final complete CSV only, so valid timeout often has no objective. |
| `xiong_single` | **Original-author** C++ repo SHA `8340e1633ba9290a567a882aff4d74f01b38102d`; audited binary SHA-256 `f58c54bb41e6e896225df40fab52b4e8e747a0967aa80ea3583c8025f2b7a2a9`. | Convert original weighted arcs to checked `W` format; invoke `RASstar -r SEED -p -o RANKS`, omit weight-replacing `-w`. One call returns rank-by-vertex; seeds 1/2, CPU, original weight objective rescored. Call may finish before cap. Source has no established redistribution grant. |
| `xiong_restarts` | Same authors' executable under **project EXP11 restart controller**, separate configuration. | Same weighted conversion; deterministic recurrence from each top-level seed invokes repeated `RASstar` calls until cap. Save/check every *complete* restart; best valid incumbent can survive a valid TIMEOUT. All restarts, conversion and overhead count. |
| `insertion_lrta`, `insertion_wmsf_l2` | Project EXP05 refinement and project initializers at frozen source above; **not Qian block insertion**. | Build respective complete order, then at most 1,000 accepted node-insertion moves under the remaining common deadline. Save valid initializer before refinement so a timeout may retain it if atomic/checksummed; initialization and refinement both count. Deterministic tie order must be pinned. |

All adapters require a strict proof that each declared vertex appears once, the same graph bytes and weights reach the method, the output is an ordering rather than merely a FAS subset, and the objective equals independently recomputed backward weight. For source-derived graphs, remove self-loops under the frozen normalization and add the recorded loop constant only when discussing original-source objective. Weighted and cardinality minima are distinct. No unlicensed third-party source/binary is committed.
